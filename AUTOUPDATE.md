
### Восстановление запуска при ошибке сети / GitHub API

Загрузчик сначала получает версию через GitHub API. Если этот путь недоступен
(например, HTTP 403 из-за лимита запросов), он загружает `widget/BUNDLE.json`
напрямую с raw.githubusercontent.com. Все три файла находятся в одном JSON,
поэтому версии не смешиваются. При полной недоступности сети нужен ранее
сохранённый офлайн-комплект; исходная ошибка теперь остаётся в диагностике.

После любой правки HTML.html, CSS.css или JS.js перед публикацией выполнить
`npm run build:bundle` и включить BUNDLE.json в тот же коммит. Поле commit
резервного комплекта — SHA-1 содержимого, а не идентификатор Git-коммита.

Чтобы установить исправление самого загрузчика, один раз замените содержимое
вкладки JS актуальным AUTOUPDATE.js, сохраните виджет и перезагрузите оверлей.
HTML/CSS должны быть пустыми при использовании загрузчика. FIELDS и DATA
для этого исправления менять не требуется. Сам загрузчик автоматически
не обновляется.
