# Установка после одобрения оформления

1. Создайте отдельный Custom Widget в StreamElements. Не заменяйте «Плашки рангов».
2. В Open Editor вставьте одноимённые файлы из `widget/` во вкладки HTML, CSS, JS,
   FIELDS и DATA. DATA используйте только при первой установке, чтобы не сбросить
   свои настройки при последующих обновлениях.
3. Нажмите Done и Save. Перезагрузите оверлей. Настройки применяются на onWidgetLoad.
4. Задайте область Custom Widget на весь оверлей: обычно 1920×1080 либо 2560×1440.
   Положение свитка задаётся в FIELDS, ширина по умолчанию 520 px.
5. Для проверки нажмите «Тестовый топ-5», затем «Закрепить свиток».
   Демонстрационные данные подписаны. «Вернуться к реальным данным» возвращает
   текущий рейтинг; при включённом изолированном тесте сначала выключите его.
6. В OBS добавьте Browser Source с URL оверлея из Copy Overlay URL.
   Размер источника должен совпадать с размером оверлея. Включите нужный FPS
   (целевой 60), проверьте видимость источника и сцену.
7. Перед эфиром отключите «Держать свиток видимым», выйдите из тестовых данных.
   Свиток автоматически впервые появится через 300 секунд после готовности.
   «Показать свиток сейчас» не меняет периодический график.

В этой версии устанавливается обычный JS.js: AUTOUPDATE.js от «Плашек рангов»
сюда не подходит. Установка автономная; SVG-декор встроен в HTML/CSS, не нужно
размещать `assets/` на стороннем хостинге. Отдельные SVG оставлены как исходники.

## Размеры и длинные сообщения

Рекомендуется Browser Source/область Custom Widget 1920×1080 или 2560×1440.
Не задавайте области Custom Widget высоту одной строки: она ограничит весь свиток.
Высота по содержимому; First Message не обрезается и не сокращается.
По умолчанию «Вписывать свиток целиком в источник» уменьшает весь свиток, если
он не помещается. Очень длинный текст станет мелким — увеличьте источник либо
уменьшите шрифт/ширину/масштаб осознанно. При отключённом вписывании показывается
диагностика требуемой высоты. OBS физически не может показать пиксели за пределами
источника: увеличьте его высоту, а затем подгоните источник в сцене.

Время полного показа задаётся отдельно. Для высоты свыше 850 CSS px добавляется
2 секунды на каждые следующие 100 px. Это не гарантирует комфортного чтения
любого объёма; для длинных сообщений установите 25–40 секунд или больше.

## Несколько копий

В OBS — «Активный». В одновременно открытом редакторе можно использовать
«Наблюдатель»: он читает сохранённую статистику, не увеличивает счётчики и не
пишет состояние. При изменении этой настройки убедитесь, что не сохранили роль
наблюдателя для единственного рабочего экземпляра в OBS. Самый простой режим —
один открытый источник, редактор закрыт после настройки. Детали в ARCHITECTURE.md.
