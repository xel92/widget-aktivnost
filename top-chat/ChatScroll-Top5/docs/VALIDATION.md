# Проверки

Проверено локально в Chromium / Playwright, 10 ноября 2026.

## Логика — 17 автоматических тестов

- Сортировка по счётчику, стабильные равенства, пять мест.
- Точный отрыв с учётом необходимости обойти равенство.
- Изменение позиции, новичок, нейтральная база после восстановления.
- Строгое first-msg=1, 0 и отсутствие признака; чужая Shared Chat-комната.
- Боты, список исключений, команды, мягкий спам-фильтр.
- Дедупликация по ID и после восстановления, ограниченный кеш ID.
- Полный First Message и отсутствие истории сообщений.
- Повреждённые снимки, будущие даты, ручная/idle сессия, срок хранения.
- Лимит пользователей, переход с логина на стабильный ID.
- Безопасный текст, URL аватаров, границы настроек.
- SE_API set без Promise, подтверждение событием, конфликт writer, резерв и observer.

## Браузер

`npm run test:browser`:

- Размеры 1920×1080 и 2560×1440.
- Короткий, средний, длинный, многоабзацный текст, эмодзи, длинная ссылка.
- Текст сохранён полностью, без горизонтального переполнения.
- Источник 600×420: автоматическое вписывание и диагностика нехватки высоты.
- Ширина 280 px, длинный ник, HTML/XSS как текст.
- Исправлена сетка при отключённых аватарах; отдельная проверка ширины текста.
- Подсчёт в скрытом состоянии, автоматический показ и исчезновение.
- Показ/закрепление/скрытие/смена тестового текста; сброс с подтверждением.
- Аватар через mock DecAPI/CDN и отказ сервиса с заглушкой.
- Повторный onWidgetLoad без удвоения обработчиков.
- Нет неожиданных pageerror, скриншот настоящего HTML/CSS в docs/PREVIEW.png.

`npm run test:runtime`:

- Полный цикл восстановления с mock SE_API и kvstore:update.
- Сохранение ID сессии, текста First Message, счётчика и ID дубликатов.
- Наблюдатель не пишет и не считает сообщения.
- Предпросмотр доступен при зависшем запросе хранилища.
- Автономная HTML-страница предпросмотра и её кнопки.

## Что ещё требует боевой проверки

Настоящие Twitch/StreamElements события, доступность first-msg для вашего канала,
реальная доставка подтверждения SE_API, публичный DecAPI/CDN из OBS, фактический
FPS на вашем компьютере. Локальные mock-события не доказывают эти интеграции.
Шаги проверки описаны в FIRST_MESSAGE.md и INSTALLATION.md.

Рабочий оверлей не изменён; эта версия подготовлена для просмотра и одобрения.
