# Настройки FIELDS

Изменения применяются после сохранения/перезагрузки. Содержимое FIELDS обновляют
вручную; новые значения DATA не нужно вставлять поверх существующей конфигурации.
Использованы документированные типы text, number, checkbox, colorpicker,
dropdown и button: https://docs.streamelements.com/overlays/widget-structure

| Раздел | Назначение |
|---|---|
| Отображение | Включение, заголовок, подзаголовок, ширина 280–1000 px, масштаб 20–200%, положение, отступы, текст 12–32 px, вписывание |
| Цвета | Пергамент, золото, текст, второстепенный текст, первое место, стрелки вверх/вниз |
| Рейтинг | 1–5 мест (5 по умолчанию), исключения, команды, защита от спама, аватары, титулы, движение, прогресс и пять редактируемых титулов |
| First Message | Блок, заголовок, полный текст 12–32 px, автор, анимация, сохранение, диагностика |
| Анимация | Интервал 300 сек., полный показ 15 сек., вход/выход 0,8 сек., направление, анимации строк/смены мест/новых участников, обновление каждые 15 сек. |
| Данные | Сохранение, интервал 15 сек., отдельный ключ, роль экземпляра, ручной/idle сброс, срок 48 ч., метка сессии, отладка, лимит 3000 участников |
| Тестирование | Изолированный режим, постоянный показ, тестовые сообщения, показ/скрытие, возврат к реальным данным, диагностика |

Полные значения, подписи, границы и типы перечислены непосредственно в FIELDS.json.

## Подсчёт и позиции

Рейтинг: сообщения по убыванию; при равенстве — время первого подходящего
сообщения по возрастанию, затем постоянный ключ пользователя лексикографически.
Таким образом места уникальны (1, 2, 3…), без случайных скачков. Изменение — между
двумя визуальными обновлениями. «Новый» означает отсутствие в предыдущем топе.
После восстановления сессии первая оценка нейтральна. Данные памяти обновляются
сразу; рендер не добавляет сообщений. Скрытый виджет продолжает учёт.

«До #N» — сколько дополнительных сообщений требуется, чтобы обойти стоящего
выше при его неизменном счётчике, с учётом правила равенства. Поэтому при
103 против 124 может быть нужно 22, а не 21. Прогресс = текущие сообщения /
(текущие + необходимое отставание). Первое место показывает полный прогресс.

Спам-фильтр по умолчанию: пауза 0,5 сек. на пользователя и подавление повторения
его последнего засчитанного текста в течение 8 сек. Хранится хеш, не история
сообщений. Оба ограничения отключаются. Команды ! по умолчанию не входят в рейтинг.
Подтверждённое First Message обрабатывается отдельно от фильтра команд/спама,
но исключённые пользователи, боты и сообщения из чужой комнаты Shared Chat
не попадают ни в рейтинг, ни в First Message.

## Тестирование

Тестовые кнопки показывают отдельную модель с подписью «Демонстрационные данные».
Они не заменяют Live-счётчики и не сохраняют искусственный First Message.
Изолированный режим дополнительно игнорирует реальные сообщения и использует
ключ Test, не Live. Для проверки настоящего чата отключите его, сохраните,
нажмите «Вернуться к реальным данным».

«Закрепить» работает до скрытия/перезагрузки. Флажок постоянного показа сохраняет
этот режим после перезагрузки. При скрытии кнопкой флажок в сохранённых настройках
не меняется. Выключите его перед обычным эфиром.
