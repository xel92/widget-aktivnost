# Архитектура и сохранение

Engine — подсчёт, фильтры, дедупликация, сортировка, снимок сессии.
Renderer — не более пяти строк, безопасный текст, асинхронные аватары, анимации.
Persistence — SE_API.store, ограниченные по времени запросы, резерв localStorage,
обнаружение конкурирующей записи. Runtime — события, восстановление, интервалы,
кнопки и очистка обработчиков при повторном запуске.

Источник: https://docs.streamelements.com/overlays/custom-widget
SE_API.store.get возвращает Promise; set не имеет документированного возврата.
Подтверждение записи принимается через kvstore:update с customWidget.<key>.
Пишется полный снимок, частичных обновлений и удаления ключа API не обещает.
Ключ ChatScrollTop5Live, в изолированном тесте ChatScrollTop5Test.
Он не пересекается с ключами «Плашек рангов».

Снимок schemaVersion=1 содержит ID сессии, время начала/активности/сохранения,
метку сброса, ограниченные записи пользователей, предыдущие позиции, последние
5000 ID событий и только последнее подтверждённое First Message. Для спам-фильтра
хранится один хеш текста на пользователя. Нет истории текста сообщений.
Период сохранения 15 сек., записи сериализованы. Подтверждённая запись сохраняется
локально. При сетевой ошибке остаётся localStorage, если браузер разрешает его.
Сохранение на pagehide — best effort: браузер не обязан дождаться async-записи.
Поэтому при аварии возможно потерять последние секунды до очередного сохранения.

Данные ограничены maxUsers (по умолчанию 3000) и сроком хранения 48 часов.
После достижения лимита новые участники не добавляются, диагностика считает
пропуски. Дедупликация гарантируется только в окне последних 5000 ID и retention.
События без надёжного ID не могут быть полностью дедуплицированы. Удалённые по
сроку хранения участники перестают влиять на рейтинг.

## Несколько экземпляров

Один активный writer. Перед записью сверяется writeId; чужой kvstore:update
блокирует учёт/запись конкурирующей копии. Observer читает начальный снимок и
подписывается на сохранённые обновления; реальные сообщения он не считает.
Без atomic compare-and-swap нет гарантированной распределённой блокировки:
два одновременных writer могут успеть перезаписать данные. Не держите активными
две копии, включая OBS и редактор. Восстановление после конфликта — оставить один
активный экземпляр и перезагрузить. Не менять ключ в надежде «слить» прогресс.

## Сессии

По умолчанию ручная сессия. Для нового эфира дважды нажмите «Сбросить сессию»
за 8 секунд. Альтернатива — изменить resetToken и сохранить (это намеренный сброс).
Опция idle сбрасывает после 6 часов общей неактивности. Это не определение начала
трансляции. Перезагрузка страницы сама по себе счётчики не обнуляет.

## Анимации и размер

Таймеры отменяются при новом показе/скрытии/перезагрузке; нет наложения очередей
анимаций. Текущий показ не прерывается периодическим таймером. Плановый интервал
отсчитывается от готовности; пропущенные из-за длительного показа слоты не копятся.
CSS использует transform/opacity; изменение высоты происходит только при данных.
ResizeObserver рассчитывает масштаб по фактическому контенту. Reduced motion
убирает движения. Целевой FPS 60, фактический FPS зависит от OBS/GPU.
