# ChatScroll — ТОП-5 ЧАТЕРОВ

Отдельный StreamElements Custom Widget: бело-золотой китайский свиток, пять
мест, сообщения, титулы по месту, изменение позиции и последнее подтверждённое
First Message. Реализация HTML/CSS/Vanilla JS, без сборщика и внешних шрифтов.

**Статус:** рабочая реализация с локальными автоматическими проверками.
Не установлен в StreamElements/OBS. Перед установкой согласуйте визуальное превью.
Реальная доставка `first-msg` и подтверждения SE_API требуют проверки на канале.

## Просмотр до установки

Откройте `preview/index.html` в браузере: файл автономный, содержит копию
HTML/CSS/JS. Выберите короткий/средний/длинный текст, эмодзи, длинную ссылку,
ширину и масштаб. Предпросмотр использует явно обозначенные демонстрационные
данные и графические заглушки аватаров, без сетевых запросов и записи Live.

Если браузер блокирует локальные iframe, запустите из этой папки:

```sh
python3 -m http.server 8092 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8092/preview/`.

## Разработка и проверки

```sh
npm install
npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
npm run build:preview
```

Браузерные тесты используют Chromium (задайте CHROMIUM_PATH для своей ОС,
либо установите браузер Playwright и адаптируйте путь). Сервер для тестов не нужен.
После изменения widget-файлов пересоберите автономное превью командой выше.

## Отдельность от «Плашек рангов»

Всё находится в `top-chat/ChatScroll-Top5/`, ветка разработки `feature/top-chat`.
Файлы `widget/` в корне репозитория относятся к «Плашкам рангов» и не менялись.
Их контрольная версия: тег `rank-cards-v1.0.0`.

Текущий ChatScroll имеет собственное хранилище и счётчики: он фильтрует команды
и спам, использует уникальные места 1–5 и титулы, привязанные к месту.
Это отличается от достижений/рангов персональных плашек. Синхронизация счётчиков
между виджетами в эту версию не включена. SE_API.store позволяет общий источник,
но согласование правил подсчёта потребует отдельного изменения обоих контрактов.

## Ограничения

Учитываются события, полученные работающим виджетом, а не история чата до его
запуска. Автоматического обнаружения начала эфира нет: ручной сброс по двойной
кнопке либо опциональный сброс после общей неактивности. Показ каждые 5 минут,
15 секунд полного отображения после появления, визуальное обновление 15 секунд.
Аватары — через документированный сторонний DecAPI с ограничением ожидания;
Twitch Helix напрямую требует OAuth. Есть автономная заглушка.
