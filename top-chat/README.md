# Топ чата / ChatScroll

Новый отдельный виджет находится в [ChatScroll-Top5](ChatScroll-Top5/README.md).
[Визуальное превью](ChatScroll-Top5/docs/PREVIEW.png).

По новому ТЗ реализован бело-золотой свиток: пять участников, сообщения,
редактируемые титулы по местам, изменение позиции, прогресс и последнее
подтверждённое First Message. Это самостоятельные счётчики с фильтрами команд
и спама; общая статистика с «Плашками рангов» пока не подключена.

Ветка разработки feature/top-chat. Установка в StreamElements/OBS не выполнена.
Файлы и автозагрузка «Плашек рангов» не изменялись. Их контрольная версия —
rank-cards-v1.0.0. Неподтверждённая проблема показа старого виджета остаётся
отдельной задачей и не считается исправленной этим проектом.
