# Ранги и статистика

По умолчанию: Адепт — 60 минут, Мастер — 120, Небожитель — 180.
Время считается с первого сообщения, а не как подтверждённое время просмотра.
В FIELDS доступны независимые пороги, названия и фразы, выключатели второго
и третьего рангов. Первый порог использует прежний rewardMinutes и сохраняет
существующую настройку. Невозрастающие пороги автоматически поднимаются до
предыдущего + 1 минуты. При выключенной системе рангов действуют прежние
thankText и allowRepeat; при включённой каждый ранг выдаётся один раз за сессию.

Сохраняются минимальное число сообщений и проверка недавней активности.
Если достигнуто несколько ступеней, показывается только высшая; более низкие
считаются пройденными. Ранг заново определяется при извлечении из очереди.
Схема хранения 2 принимает старую схему 1: уже выданная награда становится
первым рангом. Новая схема защищает прогресс от записи старой версией JS.

Место в чате определяется перед показом по числу сообщений среди сохранённых
участников текущей сессии, без исключённых пользователей и ботов.
При равенстве — одинаковое место: 1, 1, 3. Это не рейтинг всего Twitch.
Сохраняются ограничения maxUsers и retentionHours: удалённые записи не входят
в рейтинг. Тестовая анимация показывает демонстрационное место № 3.

В разделе внешнего вида: statsFont и statsFontSize (8–36 px).
Они независимо меняют всю строку статистики: время, сообщения и место.
В тестовых настройках выберите ранг и нажмите «Показать тестовую анимацию».
Изолированный тест сокращает все пороги пропорционально первому.

## Установка существующему пользователю

HTML/CSS/JS обновятся через установленный AUTOUPDATE.js. Чтобы появились новые
регуляторы, один раз замените вкладку FIELDS содержимым widget/FIELDS.json,
сохраните и обновите оверлей. DATA не заменяйте: там ваши текущие настройки.
При ручной установке обновите HTML, CSS и обычный JS вместе.

## Быстрые кнопки теста

В FIELDS добавлены «Показать оформление: Адепт / Мастер / Небожитель».
Они не требуют изолированного режима, показывают выбранный стиль даже при
выключенной системе рангов, не записывают награды и работают у наблюдателя.
Нажатия во время показа ставятся в очередь.

Для проверки условий включите изолированный тест, сохраните и перезагрузите
оверлей, затем нажмите «Запустить / повторить изолированный тест».
Флажок сам по себе не создаёт сообщения. Кнопка сбрасывает только прогресс
синтетического зрителя в Test-хранилище, создаёт не меньше minMessages сообщений
и подтверждает активность ещё одним синтетическим сообщением по окончании
testRewardSeconds. Повторный запуск снова проверяет первый порог. Реальные
сообщения игнорируются, Live-хранилище не меняется. Выключенные ранги и
исключения пользователей остаются действующими условиями теста.

Верхний заголовок при включённых рангах берётся из «Ранг N: название»,
как и подпись рядом с ником. Например, rank3Name = «Легенда» меняет оба текста.
Для одиночной награды при выключенных рангах действует прежнее поле title.
Отдельные кнопки просмотра рангов также показывают название выбранного ранга.
