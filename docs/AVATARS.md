# Аватарки зрителей вместо печати

По запросу пользователя печать заменяется круглой Twitch-аватаркой получателя благодарности. Золотая рамка, место на плашке и задержка появления эмблемы сохраняются. Если профиль или картинка недоступны, автоматически возвращается печать с мечом.

## Включение и проверка

При полном AUTOUPDATE.js HTML/CSS/JS обновляются вместе. Аватарки включены по умолчанию и не требуют перенастройки порогов или сброса сессии. Для дополнительного переключателя обновите FIELDS актуальным FIELDS.json; существующий DATA не заменяйте.

Новое поле: **«Показывать Twitch-аватар зрителя вместо печати»** (`avatarEnabled`). Выключение возвращает исходную печать и прекращает обращения за аватарками.

Для теста укажите настоящий Twitch-логин, например `xelennum`, в существующем поле «Имя тестового зрителя», сохраните и обновите оверлей. Нажмите «Показать тестовую анимацию». В реальных наградах используется логин получателя из события чата, а не тестовое имя. Тестовый режим продолжает игнорировать настоящий чат и хранить синтетический прогресс отдельно.

Обычное локальное превью отключает внешние аватарки, чтобы вымышленные тестовые зрители не создавали запросы к сервису. Их загрузка и ошибки отдельно проверяются командой `npm run test:avatars` с подменой сетевых ответов.

## Источник и ограничения

Twitch-событие чата StreamElements не содержит гарантированного URL аватара. Для получения адреса используется публичный сторонний [DecAPI](https://decapi.me/) — `GET https://decapi.me/twitch/avatar/{login}`. [Документация и кеширование](https://docs.decapi.me/cached-endpoints). Работающий запрос и CORS проверены 10 ноября 2026 года.

Токены Twitch/StreamElements не нужны. Внешнему сервису передаётся только публичный логин получателя награды. Текст чата, URL оверлея и ключи API не отправляются; запрос выполняется без учётных данных и referrer. Из ответа принимаются только HTTPS-адреса `static-cdn.jtvnw.net/jtv_user_pictures/`. Изображение также загружается без referrer.

Успешные адреса кешируются в памяти на 15 минут, неудачи — на 5 минут. Максимум 100 записей; кеш не сохраняется в SE_API.store. Сам провайдер может возвращать кешированный аватар до 30 минут: недавняя смена картинки не всегда видна немедленно. Сбой сервиса, ограничения частоты, CSP браузера, отсутствие логина и ошибки картинки приводят к возврату печати.

Проверка профиля ограничена 2,5 секунды; общий бюджет вместе с изображением — 3 секунды. Начало и окончание плашки не ждут сеть. При закрытии плашки, новом получателе и перезапуске отменяются старые запросы/обработчики, поэтому чужая запоздавшая аватарка не появится у следующего зрителя.

Загрузка зависит от доступности DecAPI и Twitch CDN в браузере StreamElements/OBS. Гарантия выдачи награды и хранение прогресса от загрузки изображения не зависят. Для возврата к ручной установке нужны все три вкладки HTML/CSS/JS из актуального репозитория.
