# Настройки StreamElements

Все поля имеют русские подписи, используются только поддерживаемые типы и свойства схемы FIELDS. Значения применяются при `onWidgetLoad`: после изменения сохраните оверлей и обновите источник. Не вставляйте повторно исходный DATA поверх пользовательских значений.

## Активность

| Поле | Назначение | По умолчанию / диапазон |
| --- | --- | --- |
| `rewardMinutes` | Минут с первого сообщения до награды | 60; 1–1440 |
| `minMessages` | Минимум сообщений для награды | 5; 1–10000 |
| `recentMinutes` | Последнее сообщение не старше, минут | 10; 1–1440 |
| `checkSeconds` | Проверка условий каждые, секунд | 15; 10–30 |
| `excludeBots` | Исключать известных ботов из встроенного списка | true |
| `excludedUsers` | Исключения: логины или ID через запятую | "" |
| `allowRepeat` | Разрешить повтор через новый интервал после награды | false |
| `maxUsers` | Предел зрителей; новые не принимаются при заполнении | 2000; 10–10000 |
| `maxQueue` | Предел очереди; остальные повторно проверяются позже | 50; 1–500 |

## Как интерпретируются значения

`rewardMinutes` — календарное время с первого сообщения. `recentMinutes` не требует сообщений на каждом отрезке: одно свежее сообщение снова подтверждает недавнюю активность. Счётчик сообщений накопительный. Это не непрерывное время просмотра.

`allowRepeat`: новый полный интервал от предыдущей награды и новое сообщение после неё; `firstSeenAt` и счётчик сохраняются. Без нового сообщения награда не повторится.

`excludedUsers`: разделители — запятая, точка с запятой или пробел; логин без учёта регистра, необязательный `@`, либо Twitch user ID. Встроенные боты: streamelements, streamlabs, nightbot, moobot, fossabot, sery_bot, wizebot, botisimo. Twitch не предоставляет универсальный надёжный признак бота в сообщении; список не исчерпывающий.

`displaySeconds` — чистое время удержания. Полная длительность = появление + показ + исчезновение. Пауза добавляется после исчезновения. По умолчанию это 8,2 секунды анимации и 1 секунда паузы. Отступ от края 36 px задан оформлением. Положение применяется относительно всей области Custom Widget, а не непосредственно сцены OBS.

`thankText` и `title` поддерживают `{displayName}`, `{minutes}` (полные минуты с первого сообщения), `{messages}`. Шаблоны выводятся как безопасный текст. Текст по умолчанию про час следует изменить при других порогах.

`saveSeconds`: объединение изменений с ограничением частоты записи. Загрузка, начало награды, ручной сброс и закрытие могут вызывать дополнительные записи. `retentionHours`: давние ненаграждённые зрители очищаются; награждённые сохраняются до конца сессии для дедупликации. При загрузке старый общий снимок не используется.

`resetMode=idle`: сброс по общей неактивности принятых сообщений, а не по факту отключения Twitch-эфира. `manual`: используйте кнопку или новый `resetToken`. Маркер сохраняется в снимке; изменение всегда намеренно сбрасывает сессию.

`storageNamespace` допускает латиницу и цифры, до 48 символов. Код удаляет неподходящие символы; используйте сразу корректное значение, чтобы два разных написания не совпали после очистки. Суффикс Live/Test добавляется автоматически. Один активный writer на ключ; observer не учитывает чат и не показывает автоматические награды.

`testMode` включает короткий порог, отдельное хранилище и игнорирование реального чата. Кнопка `testActivity` добавляет `testMessages` сообщений одному синтетическому зрителю; повторное нажатие увеличивает счётчик. Кнопка `testAlert` только показывает оформление, не меняет награды и доступна без тестового режима.

Недопустимые числа ограничиваются диапазоном, строки true/false для checkbox нормализуются, испорченные цвета заменяются дефолтами. Изменение порогов влияет и на существующий прогресс; само по себе его не удаляет. Уменьшение maxUsers может отбросить записи сверх нового лимита при восстановлении.

## Шрифт заголовка и задержка эмблемы

`titleFont` меняет только строку заголовка; имя зрителя и основной текст сохраняют свои шрифты. Используются системные семейства с безопасными запасными вариантами. Если выбранного шрифта нет в ОС, браузер использует похожий шрифт. Внешние шрифты не скачиваются.

`iconDelaySeconds` отсчитывается после завершения появления плашки. По умолчанию: 0,65 с выезд → 0,25 с пауза → 0,45 с проявление эмблемы. При коротком удержании пауза автоматически сокращается, чтобы эмблема проявилась до начала исчезновения. Для каждой новой благодарности эффект запускается заново. При reduced motion используется только прозрачность.

Для появления новых контролов в уже установленном Custom Widget обновите вкладку FIELDS актуальным FIELDS.json, сохраните и обновите оверлей. Существующий DATA не заменяйте исходным файлом: он содержит ваши настройки. Сохранённый прогресс в SE_API.store от добавления полей не сбрасывается.

## Три независимых регулятора размера

В группе «Внешний вид» доступны слайдеры размера заголовка, имени зрителя и фразы благодарности. Каждый задаёт размер в пикселях только своему элементу. После изменения сохраните и обновите оверлей. Базовый fontSize перенесён в группу «Дополнительно»: при наличии трёх явных значений он влияет только на мелкие подписи. Если установлен старый FIELDS без новых ключей, прежние пропорции заголовка/имени/благодарности сохраняются автоматически.

Для добавления контролов обновите только FIELDS актуальным FIELDS.json. Существующий DATA повторно не вставляйте: он содержит ваши настройки. Новые регуляторы не меняют текст благодарности и не сбрасывают сессию.

## Аватар получателя

`avatarEnabled` включает публичный поиск адреса аватара по логину Twitch. Изображение показывается вместо печати, при ошибке возвращается печать. Для теста `testName` должен содержать существующий Twitch-логин. Кнопка оформления не создаёт наград пользователя. Подробности: [Аватарки](AVATARS.md).
